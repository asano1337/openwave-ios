OpenWave 8 — Personal Mix

Изменения
- Hitmo остаётся первым и теперь является основой «Моей волны»: актуальные чарты + персональные поисковые семена из выбранных артистов и избранного.
- Первый запуск предлагает выбрать любимых артистов. Лайки сохраняются, видны в «Избранном» и участвуют в следующих рекомендациях.
- Нажатие на имя исполнителя открывает поиск его песен.
- Ротация исключает недавно сыгранные треки, а последняя подборка кэшируется для восстановления после краткой смены VPN.
- Маленький эквалайзер на главной странице получает частоты из реального audio-элемента через Web Audio API, а не живёт отдельной анимацией.
- Портретный интерфейс переделан как отдельный phone-first режим: нижняя навигация, компактный мини-плеер, полноэкранный экран «Сейчас играет» с большой обложкой, прогрессом, крупной центральной кнопкой и быстрыми действиями.
- Первый запуск показывается только один раз на конкретном телефоне; в выборе теперь 20 артистов, а настройки вкуса и история хранятся в localStorage.
- История поисков, прослушиваний и избранного не исчезает после закрытия приложения; на экране «Избранное» добавлены обложка коллекции, «Слушать», «Перемешать» и список сохранённых треков.
- Media Session передаёт название, автора, альбом, обложку, длительность, play/pause, next/previous и перемотку в Android-уведомления и на экран блокировки, если WebView/ОС это поддерживает.
- Добавлены PWA/iOS-метаданные, service worker и Swift WKWebView-обёртка в mobile/ios.
- Добавлен не требующий прав администратора Windows-скрипт установки OpenWave-8-Install.cmd / .ps1. Он копирует приложение в %LOCALAPPDATA%\Lo5ev\OpenWave и создаёт ярлыки с подписью Lo5ev Corp.

Файлы
- OpenWave-8-personal.exe — Windows 10/11 x64.
- OpenWave-8-mobile-new.apk — свежий Android debug APK с phone-first интерфейсом, мини-плеером, полноэкранным плеером, первым онбордингом и локальной историей; ABI arm64/armeabi-v7a/x86_64/x86.
- OpenWave-8-personal-mobile-ios-source.zip — актуальный исходный код, Android-проект, iOS Swift-обёртка, мобильный интерфейс и установщик.

VPN и источники
Hitmo-запросы идут через свежие HTTP-соединения, повторяются после ошибки и имеют резервный домен. Это помогает при смене маршрута VPN, но не может обойти VPN-провайдера, который полностью блокирует Hitmo. В этом случае используется локальный кэш последнего поиска/волны и приложение честно сообщает, что источник недоступен.

iOS
IPA нельзя собрать напрямую в Linux, но в архиве добавлены полноценный `mobile/ios/OpenWaveIOS.xcodeproj` и `.github/workflows/ios-unsigned-ipa.yml`. GitHub Actions соберёт неподписанный IPA на macOS runner; затем его нужно подписать на Windows через Sideloadly своим Apple ID. При первом запуске iOS-обёртка попросит адрес OpenWave backend. PWA-режим также позволяет открыть OpenWave в Safari и добавить его на экран «Домой».

Подпись
Lo5ev Corp используется как издатель в установщике и ярлыках. Настоящая Authenticode-подпись EXE/установщика требует сертификат издателя; без него Windows может показать SmartScreen при первом запуске, и это нельзя честно убрать поддельной подписью.

Подключение iPhone к Windows по Wi‑Fi
1. На Windows распакуй `OpenWave-8-personal.exe` и `OpenWave-8-iPhone-server.cmd` в одну папку.
2. Запусти `OpenWave-8-iPhone-server.cmd` и разреши приложению доступ к частной сети Windows Firewall.
3. Выпиши IPv4 компьютера из окна, например 192.168.1.25.
4. В iOS-приложении укажи `http://192.168.1.25:4567`.
5. Компьютер и iPhone должны быть в одной Wi‑Fi сети. Окно OpenWave и скрипт должны оставаться запущенными.
