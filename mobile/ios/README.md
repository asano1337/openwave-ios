# OpenWave iOS packaging

## Что уже подготовлено

- Веб-интерфейс получил PWA-метаданные (`manifest.webmanifest`, `sw.js`) и iOS-мета-теги.
- На iPhone его можно открыть по HTTPS в Safari и выбрать **Поделиться → На экран “Домой”**. Это даёт полноэкранный portrait-интерфейс, сохранённые лайки, обложки, LRC-текст, Media Session и кэш оболочки.
- В этой папке есть минимальная Swift/WKWebView-обёртка для сборки через Xcode. Она подключается к уже опубликованному HTTPS-адресу OpenWave.

## Почему IPA не выдан автоматически

Linux не содержит Xcode и Apple SDK. Кроме того, iOS не разрешает приложению запускать вложенный Go-процесс как Android, поэтому корректный нативный IPA требует либо доступного HTTPS backend, либо отдельного Swift/iOS backend. Для установки на устройство также нужны Apple Developer Team, provisioning profile и подпись. Фальшивый или неподписанный IPA на iPhone не установится, поэтому он намеренно не создаётся.

## Сборка и установка без Mac — пошагово

### 1. Подготовь файлы

1. Скачай `OpenWave-8-personal-mobile-ios-source.zip`.
2. Создай аккаунт на [github.com](https://github.com), если его ещё нет.
3. Создай новый **public repository**, например `openwave-ios`.
4. Распакуй архив на компьютере.
5. Загрузи в репозиторий **все папки и файлы**, включая папку `.github`.
   В корне репозитория должны быть видны `go.mod`, `web`, `mobile`, `.github` и `main.go`.

### 2. Собери IPA через GitHub

1. Открой свой репозиторий на GitHub.
2. Перейди во вкладку **Actions**.
3. Слева выбери **Build OpenWave iOS IPA**.
4. Нажми **Run workflow** → ещё раз **Run workflow**.
5. Подожди, пока появится зелёная галочка `Success`.
6. Открой завершённый запуск и прокрути страницу вниз до **Artifacts**.
7. Скачай `OpenWave-ios-unsigned`.
8. Распакуй скачанный ZIP. Внутри будет `OpenWave-ios-unsigned.ipa`.

Этот IPA ещё не подписан Apple. Его нельзя просто открыть на iPhone — сначала подпиши его через Sideloadly.

### 3. Установи Sideloadly на Windows

1. Открой [официальный сайт Sideloadly](https://sideloadly.io/).
2. Скачай версию для Windows и установи её.
3. Если программа попросит Apple Mobile Device Support или iTunes-компоненты, установи их по подсказке.
4. Подключи iPhone кабелем к компьютеру.
5. Разблокируй iPhone и нажми **Доверять этому компьютеру**.
6. В Sideloadly выбери свой iPhone в поле устройства.
7. Перетащи `OpenWave-ios-unsigned.ipa` в поле IPA.
8. Введи Apple ID. Для бесплатной установки можно использовать обычный Apple ID; пароль лучше вводить через app-specific password.
9. Нажми **Start** и дождись окончания установки.

### 4. Разреши запуск на iPhone

На iOS 16 и новее:

1. Открой **Настройки → Конфиденциальность и безопасность → Режим разработчика**.
2. Включи **Режим разработчика**.
3. Подтверди перезагрузку iPhone.
4. После перезагрузки снова подтверди включение.
5. Открой приложение OpenWave.

При бесплатной подписи приложение обычно действует 7 дней. После этого его нужно снова подписать через Sideloadly. Платный Apple Developer Account продлевает срок до года.

### 5. Подключи OpenWave к iPhone

iOS-приложение является клиентом и подключается к backend на Windows. Оно не запускает Windows EXE внутри телефона.

1. На Windows положи рядом в одну папку:
   - `OpenWave-8-personal.exe`;
   - `OpenWave-8-iPhone-server.cmd`.
2. Запусти `OpenWave-8-iPhone-server.cmd`.
3. Если Windows Firewall спросит доступ, разреши **частные сети**.
4. В окне появится IPv4 компьютера, например `192.168.1.25`.
5. Убедись, что iPhone и компьютер подключены к одной Wi‑Fi сети.
6. При первом запуске OpenWave на iPhone введи:
   `http://192.168.1.25:4567`
   Замени IP на тот, который показал скрипт.
7. Нажми **Открыть OpenWave**.

Не закрывай окно backend на Windows во время использования приложения. Если приложение не подключается, проверь IP, одну Wi‑Fi сеть и правило Windows Firewall для частной сети.

Workflow собирает неподписанный IPA на бесплатном macOS runner GitHub. Его не получится поставить напрямую: Sideloadly подпишет его перед установкой.

## Адрес backend

При первом запуске iOS-приложение попросит URL OpenWave backend. Введи HTTPS-адрес
сервера или адрес компьютера в локальной Wi‑Fi-сети, например
`http://192.168.1.25:порт`. Windows OpenWave должен быть запущен и доступен с
телефона; iOS не может запускать вложенный Windows EXE самостоятельно.
