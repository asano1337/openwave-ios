OpenWave 7 — обновлённая сборка

Что изменено
- Поиск теперь показывает единую ленту без секций «по источникам». Hitmo всегда находится первым.
- «Моя волна» полностью перестроена на актуальные Hitmo-чарты: подборка текущего года, Top 30/40/100 и популярные хиты, удаление дублей, ротация и история прослушанного.
- Нажатие на любую обложку открывает полноэкранный экран в стиле музыкального плеера: крупная обложка, название, артист, избранное, воспроизведение и текст.
- Для Hitmo автоматически подбирается качественная обложка до 1000×1000 из публичного каталога Deezer; аудио по-прежнему воспроизводится из Hitmo.
- Основной интерфейс получил атмосферный фон: падающие звёзды, мягкие световые орбиты, перспективную сетку, зерно и деликатные микроанимации. При включённом reduced motion эффекты отключаются.
- Для портретного телефона добавлен отдельный layout: нижняя навигация, компактный плеер, одноколоночная главная и вертикальная панель обложки с текстом.
- Сетевые запросы Hitmo теперь повторяются на свежих соединениях после смены VPN, используют резервный домен, а последняя волна и поисковые результаты кэшируются локально для мягкого восстановления связи.
- В экран обложки добавлена боковая панель текста песни: есть ссылка на Genius для каждой композиции, а синхронизированный LRC-текст берётся из LRCLIB, если он доступен. Строки подсвечиваются по времени аудио, автоматически прокручиваются и поддерживают клик для перемотки.
- Интерфейс адаптирован под узкие экраны и touch-управление; исходная Windows-версия продолжает использовать WebView2.
- Android APK запускает тот же Go-backend локально внутри приложения, поэтому Hitmo, волна, избранное, загрузки и тексты работают по той же схеме. В APK включены backend-варианты для arm64, armeabi-v7a, x86_64 и x86 — это исправляет запуск в MSI App Player и других эмуляторах.

Файлы
- OpenWave-7.exe — Windows 10/11 x64, неподписанный файл; нужен Microsoft Edge WebView2 Runtime.
- OpenWave-7-android-debug.apk — debug-сборка, уже подписана тестовым ключом Android и устанавливается вручную после разрешения установки из этого источника.
- OpenWave-7-source.zip — исходники, Android-проект и обновлённая инструкция.

Ограничения
- IPA здесь не собран: Apple требует macOS/Xcode, provisioning profile и сертификат разработчика для installable IPA. В Linux нельзя корректно подписать и выдать IPA, который сразу установится на iPhone. Android APK и Windows EXE собраны; iOS требует финальной сборки на Mac под Apple ID/сертификат пользователя.
- Genius не предоставляет открытый публичный API синхронизированных текстов, а его веб-страницы защищены Cloudflare, поэтому приложение открывает Genius как первоисточник, но для точного тайминга использует совместимый LRC-источник LRCLIB. Hitmo, LRCLIB и другие внешние каталоги могут менять API, ограничивать регион или права на контент. Пользователь сам отвечает за соблюдение условий источника.
